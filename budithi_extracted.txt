ABSTRACTTraffic classification is a key part of Software-Defined Wireless Networks (SDWN), where
choices made by the controller have a big impact on how well the network works. Many current methods
focus on getting the highest possible accuracy in classification, but they often don’t take into account the
real-world costs of using these models in actual networks. In this study, we look at this problem. Instead of
only aiming for the best accuracy, we consider other important factors that affect how a classifier works once
it’s in use, like the workload on the controller, how often flow rules are updated, and how much bandwidth is
used. To solve this, we created a new system called MOPSO-FFNN-AD, which uses a feed-forward neural
network along with particle swarm optimization to handle multiple goals at once. We also deal with another
challenge: network traffic isn’t the same all the time. Patterns change over time, and models trained on old
data might not work as well anymore. To fix this, we added a drift detection system based on the Page-
Hinkley method, which keeps an eye on performance and starts the process of updating the model when
changes are detected. Our tests show that it’s possible to keep good accuracy while also lowering the costs
of running the system. Plus, the system handles changes in traffic patterns fairly well. These findings show
that balancing accuracy with the cost of deploying models leads to better and more realistic solutions for
SDWN.

I. INTRODUCTION
I
N RECENT YEARS, the explosive growth of IoT ecosys-
tems, together with growing diversity in network traffic,
has led to considerable difficulties in management of wire-
less networks. The traditional architectures of the networks
do not offer a solution in the changing environment. The
development of SDWN architecture allows to separate data
and control planes to enable programmability of the network
control via a special interface, for example, OpenFlow [1].
As one of the key requirements to provide QoS in SDWNs,
traffic classification should be carried out to recognize types
of flows, such as HTTP, FTP, Video, IM, P2P traffic in real-
time, which is then necessary for implementing appropriate
control decisions.
Pradhanet al.[2] have already proposed an approach based
on PSO to optimize FFNN and obtained excellent classifi-
cation accuracy that was as high as 96% when testing the
model on popular benchmarking sets. Nevertheless, although
such an approach provides good classification quality, it
neglects additional overhead required for its implementation
in SDWN controllers, since it only maximizes classification
accuracy.
There are several performance issues that must be con-
sidered in real-world applications. First of all, continuous
variations in classifications cause more flow-rules updates,
therefore, increase consumption of bandwidth on the south-
bound interface.Secondly, the increased complexity of neural
network models imposes an extra burden on the control

of the rules leads to a longer time for installing flows into
switch memory and thus longer delays in establishing a flow.
These factors are usually neglected; however, they play an

Yet another problem is associated with the dynamic behav-
ior of the data. New applications and protocols are constantly
being developed, which results in changes in the character-
istics of traffic over time. For instance, P2P applications can
change their port numbers from 6881 to 8080. This process
is called concept drift [3] – it means that the probability
distribution of the data changes over time. Thus, a model
trained earlier becomes ineffective after some time unless
there is any sort of adaptation mechanism, which is missing
in the PSO-FFNN approach.
In order to overcome the aforementioned issues, this paper
presents a solution that takes into account both classification
accuracy and installation efficiency as well as provides adapt-
ability in case of changing conditions. The following are the
main contributions made by the paper.
1) A composite fitness function that combines classifi-
cation accuracy with various control plane overhead
considerations to create a more practical objective for
optimization;
2) A Multi-Objective Particle Swarm Optimization
(MOPSO) framework with multi-level initializations
resulting in Pareto optimizers that are appropriate in
various situations;
3) A drift detection algorithm using the Page-Hinkley
test [4] that evaluates performance and performs op-
timization at the right times; and
4) A dynamic update technique that enables the SDWN
controller to change model parameters without dis-
rupting network activities. The experiments carried
out showed that the proposed algorithm provides an
accurate solution (94.33%) as well as alternative con-
figurations to optimize performance.
The remainder of this paper is structured as follows.
Section II reviews existing literature. Section III presents
the system architecture. Section IV explains the proposed
optimization framework. Section V discusses the drift detec-
tion mechanism. Section VI provides experimental results,
followed by comparative analysis in Section VIII. Stability
considerations are discussed in Section VIII, and conclusions
are drawn in Section IX.
II. RELATED WORK
A. SDWN TRAFFIC CLASSIFICATION
Traffic classification in Software-Defined Wireless Networks
(SDWN) has been explored through multiple approaches,
including deep packet inspection (DPI), statistical feature
analysis, and machine learning-based techniques. For in-
stance, Wanget al.[5] introduced a QoS-oriented framework
that integrates semi-supervised learning with DPI to improve
classification performance. Similarly, Amaralet al.[6] im-
plemented an enterprise-level SDN solution using OpenFlow,
where multiple machine learning models were employed for
traffic identification.
In another study, Shaoet al.[7] proposed a neural-
evolutionary approach that demonstrated strong capability in
classifying network applications. Nakao and Du [8] further
explored deep learning methods by applying a multi-layer
neural architecture for mobile application detection, report-
ing an accuracy of 93.5%.
Despite these advancements, a common limitation across
these works is the exclusive focus on improving classification
accuracy. The computational and operational costs associated
with deploying such models within an SDWN controller are
not explicitly addressed.
B. MULTI-OBJECTIVE OPTIMIZATION IN NETWORKING
Multi-objective optimization approaches, especially evolu-
tionary algorithms, have found extensive application in net-
working issues like routing and resource assignment. An ex-
ample of such an approach is NSGA-II, put forward by Deb
et al.[9]. Recently, Alqarallehet al.[10] integrated swarm
intelligence with adaptive neuro-fuzzy inference system for
increasing the efficiency of routing in clustered wireless
sensor networks.
While multi-objective optimization techniques are highly
effective in tackling several objectives simultaneously, they
have primarily been employed in the domain of routing and
resource management. In contrast, the integration of MOPSO
for maximizing classification efficiency while minimizing
control-plane cost in SDWNs has received little attention in
previous literature.
C. CONCEPT DRIFT IN NETWORK TRAFFIC
The traffic behavior within network streams is dynamic by
nature, and its properties can be subject to changes over
time [3]. This property usually results in concept drift, which
means that the distribution of dataP(x,y)may vary, affect-
ing the effectiveness of previous models.
Various approaches based on statistical monitoring are
used to track such changes. For example, the Page-Hinkley
test [4] is a well-known sequential algorithm that has found
its use in quality control systems. In recent years, the ap-
proach has attracted considerable attention in online machine
learning scenarios.
Nevertheless, current SDWN-based classification schemes
do not include any drift detection mechanisms in addition
to optimizing classifier parameters. Specifically, it was not
examined whether using PSO-optimized neural networks
together with drift detection can be effectively deployed in
SDWNs.

B. SDWN INTEGRATION
The trained classifier is incorporated in the SDWN controller
to facilitate the real-time classification of flows. In case a
flow is discovered, the features of the firstkpackets are
obtained and passed to the FFNN for classification purposes.
In accordance with the class obtained, the right flow rules are
applied on the relevant switch via the OpenFlow API.
In order to make sure that the system adapts to changes
in the data, a drift detection procedure constantly checks the
performance of the classifier for several time windows. Upon
discovering a shift, the process of warm-restart optimization
by means of MOPSO takes place, without disturbing traffic
processing operations.
C. DATASET
For experimental evaluation, a synthetic SDWN traffic
dataset comprising 3,000 samples is generated, with 600
samples per traffic class. Gaussian noise with a standard
deviation ofσ= 0.35is introduced to simulate realistic
variability, resulting in an achievable accuracy range of ap-
proximately 94–96%.
To reflect practical network scenarios, certain classes—such
as HTTP and FTP—are intentionally designed to share sim-
ilar characteristics (e.g., port 80 and TCP protocol), thereby
increasing classification difficulty near decision boundaries.
The dataset is partitioned into three subsets: a fitness set
Xfit containing 2,400 samples used during optimization, a
validation subsetX val with 300 samples for evaluating flow-
rule update behavior, and a test setX te consisting of 600
samples that remains completely unseen during training.
Prior to optimization, all features are normalized to have zero
mean and unit variance to ensure stable learning.

upward shifts in a monitored statistic. We monitor the error
ratex n = 1−acc n at windown, so that accuracy drops

Remark:A common implementation error is to track

accumulate inPHn until the alarm threshold is reached.

IX. CONCLUSION
This paper presented MOPSO-FFNN-AD, the first multi-
objective neuro-evolutionary framework with adaptive drift
detection for SDWN traffic classification. Key contributions
include a five-component composite fitness function, a multi-
scale MOPSO seeding strategy that guarantees Pareto front
diversity, and a Page-Hinkley drift detector that identifies
traffic distribution shifts within 150 flows and triggers warm-
restart re-optimization.
Experimental results demonstrate that the deployed
MOPSO knee matches PSO-FFNN accuracy at 94.33% while
providing six non-dominated Pareto solutions spanning com-
posite overheadF∈[0.2249,0.2634]. Drift detection fires

for privacy-preserving adaptation.
